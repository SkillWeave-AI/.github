### Hey, we're SkillWeave

SkillWeave orchestrates AI-assisted product development across seven lifecycle phases with a set of installable skills. It works with Claude Code, Codex, Gemini CLI, Cursor, Windsurf, OpenCode, and any agent that reads Markdown or speaks MCP.

---

### What we build

- **[skillweave](https://github.com/SkillWeave-AI/skillweave)** — the core: skills, runtime, and the release contract.
- **[skillweave-sdk](https://github.com/SkillWeave-AI/skillweave-sdk)** — the SDK the core contracts are qualified against.
- **[skillweave-docs](https://github.com/SkillWeave-AI/skillweave-docs)** — documentation.
- **[skillweave-profiles](https://github.com/SkillWeave-AI/skillweave-profiles)** — profiles.

Install via [Capacium](https://github.com/Capacium/capacium).

---

### Where the work happens

The canonical repositories are maintained on self-hosted infrastructure. The repositories in this organization are the public release and distribution mirror. Issues are welcome here; pull requests are applied upstream and synchronized back automatically.
